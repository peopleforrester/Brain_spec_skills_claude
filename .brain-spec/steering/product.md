# Product Steering

## Vision
Brain Spec Skills bring structured, spec-driven development to Claude Code via zero-dependency slash commands. Planning is the highest-leverage activity in software development — Brain Spec makes it frictionless.

## Target Audience
- Solo developers using Claude Code who want structured feature planning
- Teams sharing specs via version control
- Anyone who finds blank-page spec writing intimidating (interview mode solves this)

## Core Features
1. Guided interview engine — 8 categories, 40 questions, compiles into structured specs
2. Task management with hierarchical IDs and progress tracking
3. Implementation logging with git auto-enrichment
4. Dashboard overview with fork-context isolation
5. One-line installer for any project

## Success Metrics
- Users can go from install to first spec in under 10 minutes
- Interview mode produces specs that are useful without manual editing
- Zero friction: no build step, no dependencies, no configuration

## Out of Scope
- MCP server architecture (pivoted away)
- Database-backed storage (file-based only)
- CI/CD integration (skills are passive, not automated)
- Real-time collaboration (git-based sharing only)
